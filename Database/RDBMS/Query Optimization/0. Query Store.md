না, **Query Store কোনো folder না**। এটাই সম্ভবত তোমার confusion।

SQL Server-এর **Query Store হলো database-এর ভেতরের একটি feature**, যেখানে SQL Server তোমার database-এ execute হওয়া query-গুলোর performance-related information সংরক্ষণ করে।

### সহজভাবে

তোমার database ধরো:

```text
HMS
├── Tables
├── Views
├── Stored Procedures
├── Functions
└── Query Store   ← এটা আলাদা folder না
```

Query Store **database level-এ enable** করা হয়।

---

### SSMS-এ কোথায় দেখতে পাবে?

SQL Server Management Studio (SSMS)-এ:

```text
Databases
   ↓
তোমার Database
   ↓
Query Store
```

কিছু SSMS version-এ database-এর নিচে **Query Store** নামে menu/options দেখতে পাবে।

তবে আগে Query Store **ON/Enabled** থাকতে হবে।

---

### Query Store আসলে কী store করে?

ধরো তোমার ASP.NET Core application থেকে এই query বারবার চলছে:

```sql
SELECT *
FROM Patients
WHERE CompanyId = 5
```

Query Store এই ধরনের information রাখতে পারে:

```text
Query Text
Average Duration
CPU Time
Logical Reads
Execution Count
Execution Plan
```

যেমন:

```text
Query: SELECT * FROM Patients WHERE CompanyId = 5

Executions:       50,000
Avg Duration:     120 ms
Avg CPU:          80 ms
Avg Logical Reads: 25,000
```

তখন তুমি বুঝতে পারবে:

> **এই query অনেকবার চলছে এবং প্রতিবার অনেক data পড়ছে।**

এটাই post-এর author ব্যবহার করছে।

### Query Store কি `.mdf` বা `.ldf`-এর মতো আলাদা file?

**না।**

তোমাকে Windows Explorer-এ গিয়ে:

```text
C:\Program Files\Microsoft SQL Server\...
```

এর মধ্যে কোনো `QueryStore` folder খুঁজতে হবে না।

এটা database-এর ভিতরেই manage হয়।

---

### নিজের database-এ Query Store enabled কিনা দেখবে কীভাবে?

SSMS-এ তোমার database select করে এই SQL চালাতে পারো:

```sql
SELECT 
    name,
    is_query_store_on
FROM sys.databases
WHERE name = 'YourDatabaseName';
```

যদি result হয়:

```text
name       is_query_store_on
HMS        1
```

তাহলে Query Store **enabled**।

যদি:

```text
HMS        0
```

তাহলে **disabled**।

---

### Enable করতে চাইলে

SQL Server version অনুযায়ী Query Store support থাকতে হবে। Supported version হলে:

```sql
ALTER DATABASE [HMS]
SET QUERY_STORE = ON;
```

তারপর Query Store-এ data জমা হতে শুরু করবে যখন queries execute হবে।

---

### কিন্তু একটা গুরুত্বপূর্ণ বিষয়

**Query Store enable করলেই পুরনো সব query magically পাওয়া যাবে না।**

এটা enable করার পর থেকে SQL Server query execution-এর performance information সংগ্রহ করবে। তাই তোমার application কিছুক্ষণ/কিছুদিন চললে meaningful data জমতে থাকবে।

### তোমার জন্য সবচেয়ে সহজ mental model

```text
ASP.NET Core
      ↓

      ↓
SQL Query
      ↓

      ↓
"এই Query কতবার চলেছে?"
```

তুমি চাইলে আমি তোমাকে **SSMS খুলে তোমার নিজের HMS database-এ Query Store enable করে প্রথম slow query বের করার পুরো process** একদম beginner level থেকে দেখাতে পারি।
