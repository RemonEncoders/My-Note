খুব ভালো প্রশ্ন। Linux-এ **Process Management** interview-এর একটি গুরুত্বপূর্ণ topic। নিচে সবচেয়ে বেশি ব্যবহৃত process-related command-গুলো দিলাম।

---

# ১. `ps` (Process Status)

বর্তমানে চলমান process দেখার জন্য।

```bash
ps
```

Output:

```text
PID TTY          TIME CMD
1234 pts/0    00:00:00 bash
5678 pts/0    00:00:00 ps
```

### সব process দেখতে

```bash
ps -ef
```

অথবা

```bash
ps aux
```

এটি interview-তে খুবই common।

---

# ২. `top`

Real-time process monitor।

```bash
top
```

এটি দেখায়:

- CPU Usage
    
- Memory Usage
    
- Running Processes
    
- PID
    
- User
    

এটি Windows-এর **Task Manager**-এর মতো।

---

# ৩. `htop`

`top`-এর উন্নত version।

```bash
htop
```

এটি install করতে হতে পারে:

```bash
sudo apt install htop
```

---

# ৪. `pidof`

কোন process-এর PID জানতে।

```bash
pidof nginx
```

Output:

```text
2456
```

---

# ৫. `pgrep`

Process name দিয়ে search করা।

```bash
pgrep chrome
```

---

# ৬. `kill`

কোন process বন্ধ করার জন্য।

```bash
kill PID
```

উদাহরণ

```bash
kill 2456
```

---

# ৭. `kill -9`

Forcefully process terminate করার জন্য।

```bash
kill -9 2456
```

এটিকে **SIGKILL** বলা হয়।

---

# ৮. `pkill`

PID না জেনে process name দিয়েই kill করা।

```bash
pkill firefox
```

---

# ৯. `killall`

একই নামের সব process terminate করা।

```bash
killall chrome
```

---

# ১০. `jobs`

Background jobs দেখার জন্য।

```bash
jobs
```

---

# ১১. `bg`

Stopped job-কে background-এ চালানো।

```bash
bg
```

---

# ১২. `fg`

Background job-কে foreground-এ আনা।

```bash
fg
```

---

# ১৩. `nohup`

Terminal বন্ধ হলেও process চালু রাখতে।

```bash
nohup python app.py &
```

---

# ১৪. `nice`

কম priority-তে process চালানো।

```bash
nice -n 10 python app.py
```

---

# ১৫. `renice`

চলমান process-এর priority পরিবর্তন করা।

```bash
renice 5 -p 2456
```

---

# ১৬. `pstree`

Process tree দেখায়।

```bash
pstree
```

Output:

```text
systemd
 ├── sshd
 ├── nginx
 ├── mysqld
 └── bash
```

---

# ১৭. `free`

Memory usage দেখার জন্য।

```bash
free -h
```

---

# ১৮. `vmstat`

Virtual memory এবং process statistics।

```bash
vmstat
```

---

# ১৯. `uptime`

System কতক্ষণ ধরে চলছে এবং load average দেখায়।

```bash
uptime
```

---

# ২০. `lsof`

কোন process কোন file open করেছে।

```bash
lsof
```

# Interview-তে সবচেয়ে গুরুত্বপূর্ণ Command

|Command|কাজ|
|---|---|
|`ps -ef` / `ps aux`|সব process দেখানো|
|`top`|Real-time monitoring|
|`htop`|Interactive process monitor|
|`kill`|Process terminate|
|`kill -9`|Force kill|
|`pkill`|Name দিয়ে kill|
|`killall`|একই নামের সব process kill|
|`jobs`|Background jobs দেখা|
|`bg`|Background-এ চালানো|
|`fg`|Foreground-এ আনা|
|`nohup`|Terminal বন্ধ হলেও process চালানো|
|`pidof`|PID খুঁজে বের করা|
|`pgrep`|Process search করা|
|`pstree`|Parent-child process relationship দেখা|

## Senior Developer Interview Tip 🎯

যদি interviewer বলেন:

> **"Suppose your Java application is hanging. How will you identify and kill the process?"**

একটি সাধারণ workflow হবে:

```bash
# Process খুঁজুন
ps -ef | grep java

# অথবা
pgrep java

# PID ধরে process বন্ধ করুন
kill <PID>

# যদি বন্ধ না হয়
kill -9 <PID>
```

এটি Linux System Administration, DevOps এবং Backend Developer interview-তে খুবই common scenario।
