## সাধারণ ফাইল খুঁজবেন 

### ১. `find` (সবচেয়ে বেশি ব্যবহৃত)

পুরো system-এ `report.pdf` খুঁজতে:

```bash
	find / -name "remon.jpg" 2>/dev/null
```

### এই command-এর ব্যাখ্যা

- `find` → ফাইল বা directory খোঁজার command।
    
- `/` → Root directory থেকে search শুরু করবে (অর্থাৎ পুরো system)।
    
- `-name "remon.jpg"` → `remon.jpg` নামে ফাইল খুঁজবে।
    
- `2>/dev/null` → Permission denied-এর মতো error message গুলো hide করবে।


অথবা বর্তমান directory থেকে:

```bash

	find . -name "remon.jpg"
	
```


## যদি শুধু Home directory-তে খুঁজতে চান

```bash

	find ~ -name "remon.jpg"
	
```

অথবা,

```bash

	find /home -name "remon.jpg"
	
```


যদি ফাইলটি থাকে, যেমন:

```text

	/home/remon/Pictures/remon.jpg
	
```

তাহলে output হবে:

```text

	/home/remon/Pictures/remon.jpg
	
```



## যদি filename-এর case জানা না থাকে

যদি `Remon.jpg`, `REMON.JPG`, `remon.JPG`—যেকোনো case হতে পারে, তাহলে:

```bash
	find / -iname "remon.jpg" 2>/dev/null
```

এখানে `-iname` মানে **case-insensitive** search।

---

### ২. `locate` (অনেক দ্রুত)

```bash
	
	locate remon.jpg
	
```

তবে `locate` ব্যবহার করার আগে database update থাকতে হয়।

## সহজে মনে রাখুন

|আপনি কী খুঁজছেন?|Command|
|---|---|
|`git`, `python`, `docker`, `ls` (Command)|`which`|
|`report.pdf`, `photo.jpg`, `data.txt` (সাধারণ File)|`find` বা `locate`|

### Interview Trick

যদি interviewer জিজ্ঞেস করে:

> **"You don't know where a file is located. Which command will you use?"**

তাহলে উত্তর হবে:

- **যদি এটি একটি executable command হয়** → `which`
    
- **যদি এটি সাধারণ file বা directory হয়** → `find` (বা `locate`, যদি available থাকে)
    

এটাই Linux-এ সঠিক পার্থক্য।

## Interview-তে উত্তর

যদি interviewer জিজ্ঞেস করে:

> **"How do you search a file named `remon.jpg` in the entire Linux system?"**

তাহলে আপনি বলতে পারেন:

```bash
find / -name "remon.jpg" 2>/dev/null
```

এবং ব্যাখ্যা করবেন:

> "`find` command root directory (`/`) থেকে recursiveভাবে সব directory search করে। `2>/dev/null` ব্যবহার করি যাতে permission-related error message output-এ না আসে।"

এটি Linux interview-তে একটি খুবই common এবং standard উত্তর।
