 Linux-এ **`which`** নামে একটি command আছে। এটি খুবই জনপ্রিয় একটি command।

### `which` কী কাজ করে?

`which` কোনো command-এর **executable file কোথায় আছে** (অর্থাৎ কোন path থেকে run হচ্ছে) সেটা দেখায়।

### Syntax

```bash
which [command_name]
```

### উদাহরণ ১

```bash
which python
```

Output হতে পারে:

```bash
/usr/bin/python
```

অর্থাৎ `python` commandটি `/usr/bin/python` থেকে execute হচ্ছে।

## যদি command না থাকে?

```bash
which xyz
```

Output:

```bash
which: no xyz in (/usr/local/bin:/usr/bin:...)
```

অর্থাৎ `xyz` নামে কোনো executable আপনার `PATH`-এ নেই।

---

## `which` কীভাবে কাজ করে?

Linux-এ একটি environment variable আছে:

```bash
echo $PATH
```

ধরুন Output হলো:

```bash
/usr/local/bin:/usr/bin:/bin
```

`which` এই directory গুলো এক এক করে search করে দেখে commandটি কোথায় আছে।

---

## `which` বনাম `whereis` বনাম `type`

|Command|কী দেখায়|
|---|---|
|`which git`|Executable-এর path দেখায়|
|`whereis git`|Executable, source, man page ইত্যাদি দেখায়|
|`type git`|Commandটি alias, builtin নাকি executable—সব জানায়|

উদাহরণ:

```bash
which git
```

```
/usr/bin/git
```

```bash
whereis git
```

```
git: /usr/bin/git /usr/share/man/man1/git.1.gz
```

```bash
type cd
```

```
cd is a shell builtin
```

এখানে বোঝা যাচ্ছে `cd` কোনো executable file নয়; এটি shell-এর **built-in command**।

### Interview Tip 📌

Linux interview-তে প্রায়ই জিজ্ঞেস করা হয়:

- `which` → executable কোথায় আছে?
    
- `whereis` → executable + source + man page কোথায়?
    
- `type` → commandটি builtin, alias, function নাকি executable?
    

এগুলোর পার্থক্য জানা থাকলে Linux সম্পর্কিত অনেক interview question সহজে উত্তর দিতে পারবেন।
