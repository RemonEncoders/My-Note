প্রথমে সবাই এই প্রশ্নটাই করে যে **`mv` তো Move করার জন্য, তাহলে Rename করার জন্যও কেন একই command?**

মূল বিষয়টা হলো, **Linux-এর দৃষ্টিতে Rename এবং Move আসলে একই ধরনের operation।**

### ১. যখন Rename করেন

ধরুন বর্তমান ফোল্ডারে একটি ফাইল আছে:

```bash

	test.txt

```

আপনি লিখলেন:

```bash

	mv test.txt report.txt

```

এখানে কী হলো?

- ফাইলটি কোথাও যায়নি।
    
- শুধু তার **নাম পরিবর্তন** হয়েছে।
    

অর্থাৎ:

```
test.txt  →  report.txt
```

---

### ২. যখন Move করেন

ধরুন আপনি লিখলেন:

```bash
mv test.txt /home/remon/Documents/
```

এখানে কী হলো?

- ফাইলের **নাম একই রইলো** (`test.txt`)
    
- কিন্তু **লোকেশন পরিবর্তন** হয়ে গেল।
    

অর্থাৎ:

```
/home/remon/test.txt
            ↓
/home/remon/Documents/test.txt
```

---

### ৩. Move এবং Rename একসাথে

আপনি চাইলে একই কমান্ডে দুই কাজই করতে পারেন।

```bash
mv test.txt /home/remon/Documents/report.txt
```

এখানে

- ফাইলটি `Documents` ফোল্ডারে চলে গেল।
    
- নামও `report.txt` হয়ে গেল।
    

---

## তাহলে `mv` দিয়েই Rename কেন?

Linux-এ প্রতিটি ফাইলকে **Path (পাথ)** দিয়ে চিহ্নিত করা হয়।

উদাহরণ:

```
/home/remon/test.txt
```

আপনি যখন Rename করেন:

```
/home/remon/test.txt
        ↓
/home/remon/report.txt
```

এখানে আসলে **Path-এর শেষ অংশ (filename)** পরিবর্তন হয়েছে।

Linux-এর কাছে এটা হলো **একটি Path থেকে আরেকটি Path-এ Move করা**।

অর্থাৎ,

- **Move = Path পরিবর্তন**
    
- **Rename = একই Directory-এর ভিতরে Path-এর নাম পরিবর্তন**
    

তাই Linux আলাদা `rename` command না বানিয়ে **`mv` command দিয়েই দুই কাজ করায়**।

---

## সহজভাবে মনে রাখুন

- `mv old.txt new.txt` → **Rename**
    
- `mv old.txt /folder/` → **Move**
    
- `mv old.txt /folder/new.txt` → **Move + Rename**
    

### একটি বাস্তব উদাহরণ

ধরুন আপনার বাসার ঠিকানা হলো:

```
ঢাকা, মিরপুর, বাসা-১০
```

**Case 1:** আপনি একই বাসায় থাকেন, শুধু বাসার নাম পরিবর্তন করলেন।

```
বাসা-১০ → বাসা-২০
```

এটা অনেকটা **Rename**।

**Case 2:** আপনি নতুন এলাকায় চলে গেলেন।

```
মিরপুর → উত্তরা
```

এটা **Move**।

**Case 3:** আপনি নতুন এলাকায় গেলেন এবং বাসার নম্বরও বদলে গেল।

```
মিরপুর, বাসা-১০
        ↓
উত্তরা, বাসা-২০
```

এটা **Move + Rename**।

Linux-এর `mv` command এই তিনটি কাজই করতে পারে।
