খুব ভালো প্রশ্ন। **"Executable command"** বলতে কী বোঝায়, এটা বুঝলে `which`, `PATH`, `bash`—সবকিছুই অনেক সহজ হয়ে যাবে।

## প্রথমে "Executable" মানে কী?

**Executable** মানে হলো **এমন একটি file যেটি CPU সরাসরি execute (run) করতে পারে**।

Windows-এ যেমন:

```text
chrome.exe
notepad.exe
```

এগুলো executable file।

Linux-এ সাধারণত `.exe` extension থাকে না। তাই আপনি দেখবেন:

```text
/usr/bin/git
/usr/bin/python3
/bin/ls
/bin/mv
```

এগুলোও executable file, শুধু `.exe` নেই।

## Command আসলে কী?

যখন আপনি Terminal-এ লিখেন:

```bash
ls
```

তখন Bash shell কী করে?

১. `ls` নামে কোনো executable খুঁজে।  
২. `PATH` variable-এর directory গুলোতে search করে।  
৩. `/bin/ls` পেয়ে গেলে সেটি execute করে।

অর্থাৎ,

আপনি লিখেছেন:

```bash

	ls
	
```

কিন্তু আসলে `Linux execute` করছে:

```bash

  /bin/ls

```

## আরেকটি উদাহরণ

আপনি লিখলেন:

```bash
git
```

Bash খুঁজে পেল:

```text
/usr/bin/git
```

তাই

```bash
git status
```

আসলে execute হচ্ছে:

```bash
/usr/bin/git status
```

---

## `which` কী করে?

যখন লিখেন:

```bash
which git
```

Output:

```text
/usr/bin/git
```

মানে `git` command-এর executable file এখানে আছে।

## কিন্তু `report.pdf` কেন executable না?

ধরুন আপনার কাছে একটি PDF আছে।

```text
/home/remon/report.pdf
```

আপনি কি Terminal-এ লিখতে পারবেন?

```bash
report.pdf
```

না।

কারণ এটি কোনো executable program নয়। এটি শুধু একটি document।

তাই

```bash
which report.pdf
```

কাজ করবে না।

## Interview-তে এভাবে বলবেন

> **Executable command** হলো এমন একটি command যার পিছনে একটি executable program থাকে। যখন আমরা Terminal-এ `git`, `ls` বা `python` লিখি, shell `PATH`-এর মধ্যে সেই executable file খুঁজে বের করে এবং সেটি execute করে। `which` command এই executable file-এর location দেখায়।

## একটি সহজ analogy 🎯

ধরুন আপনার কাছে একটি রিমোট কন্ট্রোল আছে।

- **TV** = Executable Program
    
- **TV Remote-এর Power Button** = Command
    

আপনি শুধু **Power** বাটন চাপেন (`ls`)।

কিন্তু আসলে যে কাজটি হচ্ছে, তা TV (অর্থাৎ executable `/bin/ls`) করছে।

ঠিক তেমনই:

```bash
ls
```

আসলে execute হচ্ছে:

```bash
/ bin / ls
```

এজন্যই `which ls` আপনাকে `/bin/ls` দেখায়। আর `which report.pdf` কিছুই দেখায় না, কারণ `report.pdf` কোনো executable program নয়।
