এটা Linux-এর খুবই গুরুত্বপূর্ণ একটি concept। চলুন ধাপে ধাপে বুঝি।

আপনি যখন লিখেন:

```bash
find / -name "remon.jpg"
```

`find` পুরো system search করবে।

কিন্তু `/etc`, `/root`, `/proc` ইত্যাদি অনেক directory সাধারণ user access করতে পারে না।

তখন আপনি এমন error দেখতে পাবেন:

```text

	find: '/root': Permission denied
	find: '/proc/1234/fd': Permission denied
	find: '/var/lib/...': Permission denied
	
```

ধরুন আপনার আসল output হলো:

```text

	find: '/root': Permission denied
	find: '/proc/1234/fd': Permission denied
	/home/remon/Pictures/remon.jpg
	find: '/var/cache': Permission denied
	
```

এখন আসল result-এর সাথে অনেক error message মিশে গেছে।

---

## তাহলে `2>/dev/null` কী করে?

```bash

	find / -name "remon.jpg" 2>/dev/null
	
```

এখানে,
	
- `2>` মানে **stderr (Standard Error)**-কে অন্য জায়গায় পাঠাও।
	
- `/dev/null` - হলো Linux-এর একটি special file, যাকে **black hole** বলা হয়।
	

যা কিছু এখানে পাঠানো হয়, সব **ফেলে দেওয়া হয় (discard)**।

---

## `2` কেন?

Linux-এ প্রতিটি program-এর ৩টি standard stream থাকে।

`0` - **stdin** - *take Input *
`1` - **stdout** - *Normal Output*
`2` - **stderr** - *Error Message*


উদাহরণ:

```bash

	echo "Hello"
	
```

Output:

```text

	Hello
	
```

এটা **stdout (1)**।

কিন্তু

```bash
cat abc.txt
```

যদি file না থাকে:

```text
cat: abc.txt: No such file or directory
```

এটা **stderr (2)**।

---

### `find`-এর ক্ষেত্রে

Normal result:

```text

	/home/remon/Pictures/remon.jpg

```

এটা **stdout (1)**।

Error:

```text

	find: '/root': Permission denied

```

এটা **stderr (2)**।

আপনি যখন লিখেন

```bash

	find / -name "remon.jpg" 2>/dev/null

```

তখন

- ✅ আসল result দেখাবে
    
- ❌ Error message লুকিয়ে ফেলবে
    

Output:

```text

	/home/remon/Pictures/remon.jpg

```

---

## `/dev/null` কী?

এটাকে আপনি **dustbin** বা **black hole** হিসেবে ভাবতে পারেন।

যা পাঠাবেন, সব হারিয়ে যাবে।

উদাহরণ:

```bash

	echo "Hello" > /dev/null

```

এখানে "Hello" কোথাও দেখাবে না।

কারণ output সরাসরি `/dev/null`-এ গেছে।

## Interview Tip

Interviewer যদি জিজ্ঞেস করে:

> **Why do we use `2>/dev/null` with `find`?**

আপনি বলতে পারেন:

> **`find` command পুরো filesystem search করার সময় অনেক directory-তে permission থাকে না। ফলে `Permission denied` error আসে। `2>/dev/null` ব্যবহার করলে stderr (file descriptor 2)-এর সব error message `/dev/null`-এ redirect হয়ে যায়, তাই শুধু আসল search result দেখা যায়।**

এটি Linux interview-তে খুবই common একটি প্রশ্ন, কারণ এর মাধ্যমে তারা যাচাই করে আপনি **stdin (0), stdout (1), stderr (2)** এবং **redirection (`>`, `2>`)** সম্পর্কে ধারণা রাখেন কিনা।
