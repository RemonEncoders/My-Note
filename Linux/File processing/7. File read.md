খুব ভালো প্রশ্ন। `cat` (Concatenate) Linux-এর অন্যতম গুরুত্বপূর্ণ command। যদিও অনেকে মনে করেন `cat` শুধু file পড়ার জন্য, কিন্তু আসলে এর আরও অনেক ব্যবহার আছে।

চলুন একে একে দেখি।

---

# ১. File-এর Content দেখা (সবচেয়ে Common)

ধরুন `notes.txt`-এ লেখা আছে:

```text
Hello Linux
I am Remon
```

Command:

```bash
cat notes.txt
```

Output:

```text
Hello Linux
I am Remon
```

👉 **ব্যবহার:** File-এর content পড়া।

---

# ২. একাধিক File-এর Content একসাথে দেখা

ধরুন

`file1.txt`

```text
Hello
```

`file2.txt`

```text
World
```

Command:

```bash
cat file1.txt file2.txt
```

Output:

```text
Hello
World
```

👉 **ব্যবহার:** একাধিক file একসাথে display করা।

---

# ৩. নতুন File তৈরি করা

```bash
cat > notes.txt
```

এখন লিখুন:

```text
Hello Linux
I love Ubuntu
```

শেষে **Ctrl + D** চাপুন।

`notes.txt` তৈরি হবে এবং content save হবে।

# Interview Summary

Interviewer:

> **What are the uses of the `cat` command?**

আপনি বলতে পারেন:

1. File-এর content display করা।
    
2. Multiple file concatenate করা।
    
3. নতুন file তৈরি করা।
    
4. File copy করা।
    
5. File merge করা।
    
6. File-এ content append করা।
    
7. Line number দেখানো (`-n`)।
    
8. Special character দেখানো (`-A`, `-T`)।

## `cat` vs `echo` (খুব গুরুত্বপূর্ণ)

|`echo`|`cat`|
|---|---|
|নিজের text print করে|File-এর content পড়ে|
|Variable print করতে পারে|File merge করতে পারে|
|File-এ এক/কয়েক লাইন লিখতে পারে|File create, read, concatenate করতে পারে|
|Data **generate** করে|Existing data **display/manipulate** করে|

### সহজভাবে মনে রাখুন

- **`echo` = "আমি কিছু বলছি।"** (নিজে output তৈরি করে)
    
- **`cat` = "আমাকে একটা file দাও, আমি তার ভেতরের লেখা দেখাব।"**
    

এই একটি পার্থক্য বুঝে গেলে `echo` এবং `cat` নিয়ে আর কখনও বিভ্রান্ত হবেন না।
