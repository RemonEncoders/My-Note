# 1. Line Number দেখানো

```bash

	cat -n notes.txt
	
```

Output:

```text

	1  Hello Linux
	2  I am Remon
	
```

👉 Interview-এ মাঝে মাঝে এই option জিজ্ঞেস করা হয়।

---

# 2. Blank Line Number দেখানো

```bash

	cat -b notes.txt
	
```

এটি শুধু non-empty line-এ number দেয়।

---

# 3. Invisible Character দেখানো

```bash

	cat -A notes.txt
	
```

Output হতে পারে

```text

	Hello$
	Linux$
	
```

এখানে `$` দ্বারা line ending বোঝানো হচ্ছে।

এটি debugging-এর সময় কাজে লাগে।

---

# 4. Tab Character দেখানো

```bash

	cat -T file.txt
	
```

Tab-কে `^I` হিসেবে দেখাবে।

---

# `cat` কেন "Concatenate"?

কারণ এর আসল উদ্দেশ্য ছিল **একাধিক file-কে concatenate (জোড়া লাগানো)**।

উদাহরণ:

```bash
cat part1.txt part2.txt part3.txt > complete.txt
```

এখানে তিনটি file একসাথে merge হয়ে `complete.txt` তৈরি হবে।
