## Table 3 : ApprovalPolicy

### উদ্দেশ্য

এই Table শুধু Amount Range Match করবে।

```
ApprovalPolicy
------------------------------------------------------
PK  PolicyId

    MinAmount

    MaxAmount

FK  WorkflowId

    IsActive
------------------------------------------------------
```

### Example
### ApprovalPolicy Example

|PolicyId|MinAmount|MaxAmount|Workflow|
|---|---|---|---|
|1|0|99999|Workflow 1|
|2|100000|999999|Workflow 2|
|3|1000000|NULL|Workflow 3|

Or if you don't want a table, simply write it like this:

```text

	PolicyId    MinAmount    MaxAmount    Workflow
	
	1           0            99999        Workflow 1
	2           100000       999999       Workflow 2
	3           1000000      NULL         Workflow 3
	
```

> NULL মানে Unlimited।

# ৬. ApprovalPolicy এবং PRApproval-এর সম্পর্ক

এখানেই সবচেয়ে বেশি Confusion হয়।

অনেকেই মনে করে এই দুই Table-এর মধ্যে Foreign Key Relationship থাকবে।

আসলে তা নয়।

পুরো Flow হলো—

```
PurchaseRequest
       │
       ▼
ApprovalPolicy
       │
       ▼
ApprovalWorkflow
       │
       ▼
ApprovalWorkflowStage
       │
       ▼
PRApproval
```

---

## Step 1 : PurchaseRequest

ধরা যাক User একটি PR করল।

```
PR-1001

Amount = 1,250,000
```

এখনও System জানে না কে Approve করবে।

---

## Step 2 : ApprovalPolicy

System Amount দেখে।

```
Min        Max          Workflow

0          99,999       Workflow 1

100000     999999       Workflow 2

1000000    NULL         Workflow 3
```

তারপর Query হবে

```sql
SELECT WorkflowId
FROM ApprovalPolicy
WHERE
1250000 >= MinAmount
AND
(MaxAmount IS NULL OR 1250000 <= MaxAmount)
```

Result

```
WorkflowId = 3
```

এখানেই ApprovalPolicy-এর কাজ শেষ।

এটা শুধু বলে—

> "এই Amount-এর জন্য Workflow 3 ব্যবহার করো।"

---

## Step 3 : ApprovalWorkflow

Workflow নির্বাচন হয়ে গেলে PurchaseRequest-এ

```
WorkflowId = 3
```

সংরক্ষণ করা হয়।

Relationship

```

        |

```

# ৭. Database Relationship Summary

### ১.

```
ApprovalWorkflow

1 ------< PurchaseRequest
```

একটা Workflow অনেক PurchaseRequest-এ ব্যবহার হতে পারে।

---

### ২.

```
ApprovalWorkflow

1 ------< ApprovalWorkflowStage
```

একটা Workflow-এর অনেক Stage থাকে।

---

### ৩.

```
PurchaseRequest

1 ------< PRApproval
```

একটা PR-এর অনেক Approval Record থাকবে।

---

### ৪.

```
ApprovalWorkflowStage

1 ------< PRApproval
```

একটি Stage Definition অনেক PR-এর Approval History-তে ব্যবহৃত হতে পারে।

---

### ৫.

ApprovalPolicy-এর কোনো Direct Foreign Key Relationship PRApproval-এর সাথে নেই।

এটা একটি Rule/Configuration Table।

এর কাজ শুধু—

```
Amount

↓

Workflow নির্বাচন

↓

PurchaseRequest.WorkflowId সেট করা
```

তারপর থেকে পুরো Approval Process পরিচালনা করে—

- ApprovalWorkflow
    
- ApprovalWorkflowStage
    
- PRApproval
