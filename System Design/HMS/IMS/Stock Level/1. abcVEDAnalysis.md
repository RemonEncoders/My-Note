## মূল ডিজাইন-সিদ্ধান্ত (সবার আগে এটা বুঝা জরুরি)

পেজটা **হিসাব করবে না — পড়বে।** Recalculate বাটন (যা এখনই কাজ করে) DB-তে stamp করে; Analysis পেজ আর StockLevels পেজ দুটোই সেই stamped মান পড়বে। তাহলে দুই পেজে ABC কখনো অমিল হবে না — এটাই আপনার "alignment"-এর মূল সূত্র।

কিন্তু একটা ফাঁক আছে: ABC tab-এ **Annual Value** (৳) দেখাতে হবে, অথচ recalc এখন শুধু class stamp করে, value-টা ফেলে দেয়। তাই:

> **সুপারিশ:** Product entity-তে আরেকটা কলাম যোগ করুন — `AbcAnnualValue (double?)` — যা `RunAbcAnalysisAsync()` class stamp করার সময় একসাথে stamp করবে ([ProductRepository.cs:713-714](vscode-webview://0tri44ar51et483btke71i178mqksugck1rce8n1q6b1u371eioe/HMS.Repository/ProductRepository.cs#L713-L714)-এ মাত্র ১ লাইন যোগ)। তাহলে Analysis পেজ হবে Products টেবিলের উপর একটা সস্তা `GroupBy` — প্রতি page load-এ ১২ মাসের transaction পুনরায় স্ক্যান করতে হবে না, আর পেজে দেখানো value হবে ঠিক সেটাই যা দিয়ে class নির্ধারিত হয়েছিল (drift হবে না)।

বিকল্প ছিল প্রতি visit-এ value পুনরায় হিসাব করা — কিন্তু সেটা ভারী query এবং recalc-এর পরে consumption বদলালে class আর value অসঙ্গত দেখাবে। তাই stamped পথই সঠিক, এবং এটা আপনার বিদ্যমান `AbcClass` stamping দর্শনেরই সম্প্রসারণ।

## ধাপে ধাপে Procedure

**ধাপ ১ — Entity + Migration** (`HMS.Entities`, `HMS.Repository`)

- `Product.cs`-এ `public double? AbcAnnualValue { get; set; }` যোগ
- একটা migration: `AddAbcAnnualValueToProduct` (আপনার আগের `AddStockLevelPhase0Fields` migration-এর মতোই ছোট)

**ধাপ ২ — ViewModel classes** (`HMS.Entities/NotMapped/AbcAnalysisResult.cs`-এর পাশে, `StockLevelQuery.cs`-এর স্টাইলে)

```
AbcVedQuery        → CategoryId (ফিল্টার), IQueryObject লাগবে না (paging নেই)
AbcClassRow        → Class, ItemCount, SkuPct, Value, ValuePct, CumulativePct
VedClassRow        → Ved, ItemCount, SkuPct, Value, ValuePct
AbcVedMatrixCell   → Abc, Ved, ItemCount, Value
AbcTopItem         → ProductCode, ProductName, AnnualValue, CumulativePct
AbcVedAnalysisVm   → AbcRows, VedRows, MatrixCells, TopAItems, CalculatedOn, TotalValue
```

**ধাপ ৩ — Repository** ([ProductRepository.cs](vscode-webview://0tri44ar51et483btke71i178mqksugck1rce8n1q6b1u371eioe/HMS.Repository/ProductRepository.cs), Stock Level Report region-এর মতো নিজস্ব `#region`-এ)

- `GetAbcVedAnalysisAsync(AbcVedQuery query)`:
    - Base: `Products.Where(!IsDeleted && ItemType == Product && CategoryId ফিল্টার)`
    - ABC rows: `GroupBy(p.AbcClass)` → count + `Sum(AbcAnnualValue)`
    - VED rows: `GroupBy(p.ProductImportanceLevel)` (VED তো এমনিতেই Product-এ আছে, কিছু stamp করা লাগে না)
    - Matrix: `GroupBy(new { p.AbcClass, p.ProductImportanceLevel })` → ৯ cell
    - Top A items: `Where(AbcClass == A).OrderByDescending(AbcAnnualValue).Take(10)`
    - `CalculatedOn = Max(p.AbcCalculatedOn)` — **এতে সেই write-only property-টাও অবশেষে কাজে লাগবে** ("ABC as of: …" দেখাতে)
- `RunAbcAnalysisAsync()`-এ ১ লাইন: `v.Product.AbcAnnualValue = v.Value;`

**ধাপ ৪ — Contracts + Service** (`IProductRepository`, `IProductService`, `ProductService`)

- `StockLevelReportAsync`-এর মতোই এক-লাইনের passthrough ([ProductService.cs:135-141](vscode-webview://0tri44ar51et483btke71i178mqksugck1rce8n1q6b1u371eioe/HMS.Services/ProductService.cs#L135-L141) দেখুন)

**ধাপ ৫ — Web Model** (`HMS.Web/Areas/IMS/Models/AbcVedAnalysisModel.cs`)

- [StockLevelModel.cs](vscode-webview://0tri44ar51et483btke71i178mqksugck1rce8n1q6b1u371eioe/HMS.Web/Areas/IMS/Models/StockLevelModel.cs)-এর হুবহু pattern: Autofac resolve, Category dropdown-এর `SelectList`, service-এ delegate। (হ্যাঁ, service-locator pattern-টা আদর্শ না, কিন্তু আপনি existing convention-এ anchor চেয়েছেন — তাই এটাই।)

**ধাপ ৬ — Controller** ([AbcVedAnalysisController.cs](vscode-webview://0tri44ar51et483btke71i178mqksugck1rce8n1q6b1u371eioe/HMS.Web/Areas/IMS/Controllers/AbcVedAnalysisController.cs))

- `Index(AbcVedQuery query)` → model থেকে VM এনে view-তে পাঠানো; TempData summary যেমন আছে থাকবে

- নতুন `ExportToExcel(AbcVedQuery query)` — StockLevelsController-এর EPPlus pattern কপি করে ABC summary + Top items sheet

**ধাপ ৭ — View** ([Index.cshtml](vscode-webview://0tri44ar51et483btke71i178mqksugck1rce8n1q6b1u371eioe/HMS.Web/Areas/IMS/Views/AbcVedAnalysis/Index.cshtml))

- `@model AbcVedAnalysisVm` (বা query) ঘোষণা; সব hardcoded সংখ্যা model loop দিয়ে প্রতিস্থাপন

- চাইলে Pareto/Donut placeholder-এ Chart.js — তবে এটা ঐচ্ছিক শেষ ধাপ

**ধাপ ৮ — যাচাই**

## কেন এটা আপনার existing solution-এর সাথে সঠিকভাবে নোঙর করে

- StockLevels আর AbcVedAnalysis **একই stamped source** পড়ে — কখনো অমিল হবে না
- Layering, NotMapped VM, EPPlus export, dropdown-model — সব বিদ্যমান convention-এর প্রতিলিপি
- `Recalculate` = একমাত্র লেখক (writer), বাকি সব পাঠক (reader) — দায়িত্ব পরিষ্কার
- একটামাত্র schema পরিবর্তন, তাও বিদ্যমান stamping কলামগুলোর পাশেই

রাজি থাকলে বলুন — আমি ধাপ ১ থেকে ৮ পর্যন্ত পুরোটা implement করে দিচ্ছি।
