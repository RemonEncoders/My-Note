চমৎকার প্রশ্ন — এটা ABC analysis-এর সবচেয়ে common confusion। বিস্তারিত বুঝিয়ে বলছি।

## মূল কথা: ABC হলো product-এর "পরিচয়", stock-এর "অবস্থা" না

Stock Levels report-এ দুই ধরনের information পাশাপাশি দেখানো হয়:

|ধরন|Column|কত ঘনঘন বদলায়|
|---|---|---|
|**অবস্থা** (এখন কী হচ্ছে)|Current Qty, Status, DoC|প্রতি transaction-এ বদলায়|
|**পরিচয়** (item-টা কতটা গুরুত্বপূর্ণ)|VED, ABC|মাসে/কোয়ার্টারে একবার review হয়|

খেয়াল করুন — **VED-ও কিন্তু একই রকম।** Adrenaline "V - Vital", এটা আপনি product-এ set করে রেখেছেন (`ProductImportanceLevel`)। আজ stock ১০০ থাকুক বা ০ — সে Vital-ই থাকবে। ABC-ও ঠিক তাই, শুধু পার্থক্য হলো VED ঠিক হয় **clinical গুরুত্ব** দিয়ে (manually), আর ABC ঠিক হয় **টাকার অঙ্ক** দিয়ে (calculation করে)। Stock Levels page এই badge দুটো শুধু **দেখায়**, page-এর data থেকে **হিসাব করে না**।

## কেন current stock value দিয়ে ABC করলে ভুল হবে

ধরুন current stock × price দিয়ে ABC করলেন। আপনার mockup-এর data দিয়েই দেখাই:

**Case 1 — Stock-out item:** Adrenaline Inj, current qty = **0**।

- Current stock value = 0 × দাম = **০ টাকা** → ranking-এ সবার নিচে → **C class!**
- অথচ এটাই হাসপাতালের সবচেয়ে critical item, যেটা এইমাত্র শেষ হয়ে গেছে।
- Stock Levels page-এর মূল কাজটাই হলো চিৎকার করে বলা: **"A-class Vital item stock-out — এক্ষুনি ব্যবস্থা নিন!"** কিন্তু current stock দিয়ে হিসাব করলে item-টা stock-out হওয়া মাত্রই A থেকে C-তে নেমে যাবে — মানে যখন সবচেয়ে বেশি alert দরকার, ঠিক তখনই report চুপ হয়ে যাবে।

**Case 2 — Excess slow-moving item:** Bed Sheet, current qty = **3,840** (excess)।

- Current stock value = 3,840 × দাম = অনেক টাকা → **A class!**
- অথচ এটা বছরে সামান্যই consume হয় — আসলে C item। ভুল কেনাকাটার ফলে গুদামে জমে থাকা মালকে report বলবে "সবচেয়ে গুরুত্বপূর্ণ item"।

**Case 3 — অস্থির classification:** সকালে Ceftriaxone-এর ৪১২ vial আছে → A; দুপুরে বড় issue হলো, ৫০ vial থাকল → C; পরদিন GRN ঢুকল → আবার A। যে classification প্রতিদিন বদলায়, সেটা দিয়ে কোনো policy (কড়া monitoring, cycle count frequency, reorder priority) বানানো যায় না।

## তাহলে consumption value কেন?

ABC-এর আসল উদ্দেশ্য: **"বছরের টাকাটা কোন item-গুলোর পেছনে যায়?"** — সেটা জানা, যাতে সেগুলোর ওপর কড়া নিয়ন্ত্রণ রাখা যায়। ছোট example:

|Item|বার্ষিক consumption|WAC|Annual value|Value %|Cumulative|Class|
|---|---|---|---|---|---|---|
|Insulin|12,000 vial|৳400|৳48,00,000|48%|48%|**A**|
|Ceftriaxone|30,000 vial|৳90|৳27,00,000|27%|75%|**A**|
|Syringe 10cc|2,00,000 pcs|৳8|৳16,00,000|16%|91%|**B**|
|Paracetamol|5,00,000 tab|৳1.2|৳6,00,000|6%|97%|**C**|
|Bed Sheet|500 pcs|৳600|৳3,00,000|3%|100%|**C**|

দেখুন — Paracetamol volume-এ সবচেয়ে বেশি চললেও টাকার হিসাবে C, আর Insulin-এ বছরের প্রায় অর্ধেক টাকা যায় বলে A। এই ranking current stock কত আছে তার ওপর নির্ভর করে না — করে **সারা বছরের flow**-এর ওপর।

## Stock Levels page-এ তাহলে ABC-এর ভূমিকা কী?

দুটো axis মিলিয়েই এই report-এর আসল শক্তি:

- **A + Stock-Out** → সর্বোচ্চ emergency (টাকার দিক থেকে সবচেয়ে গুরুত্বপূর্ণ item নেই!)
- **A + Excess** → অনেক টাকা গুদামে আটকে আছে → purchase কমান
- **C + Low** → তেমন চিন্তার কিছু না, routine reorder-এ হবে
- **C + Excess** → ঠিক আছে, দাম কম, পড়ে থাকুক

মানে ABC column-টা বলে দেয় **কোন row-টা আগে দেখবেন** — এজন্যই mockup-এ sorting "Critical first" আর A/V badge পাশাপাশি।

## Implementation-এ এর মানে

- ABC calculation Stock Levels query-র ভেতরে হবে **না**। এটা আলাদাভাবে হবে — হয় monthly/quarterly background job, নয়তো আপনার existing [AbcVedAnalysisController](vscode-webview://0tri44ar51et483btke71i178mqksugck1rce8n1q6b1u371eioe/HMS.Web/Areas/IMS/Controllers/AbcVedAnalysisController.cs) page থেকে "Recalculate" button — যেখানে গত ১২ মাসের issue qty × WAC দিয়ে ranking হবে, result টা Product-এ store হবে (যেমন nullable `AbcClass` field, `ProductImportanceLevel`-এর মতোই)।
- Stock Levels report তখন শুধু stored `AbcClass` badge-টা দেখাবে — VED যেভাবে দেখাচ্ছে, ঠিক সেভাবে। Query-তে বাড়তি কোনো ভারী aggregation লাগবে না, page ও fast থাকবে।

আর যদি আপনার আসলে দরকার হয় **"এই মুহূর্তে কোন item-এ কত টাকা আটকে আছে"** — সেটা valid প্রশ্ন, কিন্তু সেটার নাম ABC analysis না, সেটা **Inventory Valuation report** (current qty × cost) — চাইলে সেটাও Stock Levels-এ একটা "Stock Value" column হিসেবে যোগ করা যায়, ABC-এর পাশাপাশি।
