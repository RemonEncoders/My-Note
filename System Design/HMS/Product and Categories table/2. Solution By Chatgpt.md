# Solution 1: শুধু `ItemType` ব্যবহার করা (বর্তমান Design)

এটাই আপনার বর্তমান Database Design।

## Category Table

|Id|Name|CategoryType|
|---|---|---|
|1|Finished Goods|Product|
|2|Technical Services|Product|
|3|Raw Materials|Material|

## Product Table

|Name|ItemType|CategoryId|
|---|---|---|
|Laptop|Product|1|
|Installation Charge|Service|2|
|Cement|Material|3|

---

## Rule

```text
Product না Service তা নির্ধারণ করবে ItemType।
Category শুধু Grouping।
```

---

## Validation

কোন Validation লাগবে না।

```csharp
product.ItemType = EnumItemTypes.Service;
```

এটাই যথেষ্ট।

---

## সুবিধা

- Simple Design
    
- Database Change লাগবে না।
    
- Existing Code Break হবে না।
    

---

## অসুবিধা

নিচের Invalid Data Save হয়ে যাবে:

|Name|ItemType|Category|
|---|---|---|
|Laptop|Product|Technical Services|

এটাকে Database আটকাবে না।

# Solution 2: Category অনুযায়ী Filter করা (UI Level Validation)

এখানে Database Change করব না।

ধরি:

```text
Service Page
```

থেকে Add করলে:

```csharp
ItemType = Service;
```

তখন Dropdown-এ শুধু Service Category দেখাবো।

---

## কিন্তু Problem

আপনার Category Entity-তে এমন কোনো Property নেই:

```csharp
IsServiceCategory
```

বা

```csharp
AllowedItemType
```

তাই "Technical Services" Category যে Service-এর জন্য, সেটা Database বুঝতে পারছে না।

আপনাকে Name দেখে Filter করতে হবে:

```csharp
.Where(x => x.Name.Contains("Service"))
```

---

## এটা খারাপ Design কেন?

কারণ:

```text
Technical Services
```

এর নাম পরে কেউ Change করে:

```text
Technical Support
```

তখন Code ভেঙে যাবে।

# Solution 3: Category-তে `AllowedItemType` Add করা (Recommended)

Category Entity:

```csharp
public EnumItemTypes AllowedItemType { get; set; }
```

---

## Category Table

|Name|AllowedItemType|
|---|---|
|Finished Goods|Product|
|Technical Services|Service|
|Raw Materials|Material|

---

## UI Filter

Service Page:

```csharp
.Where(x => x.AllowedItemType == EnumItemTypes.Service)
```

Product Page:

```csharp
.Where(x => x.AllowedItemType == EnumItemTypes.Product)
```

Material Page:

```csharp
.Where(x => x.AllowedItemType == EnumItemTypes.Material)
```

---

## Save Validation

```csharp
if(product.ItemType != category.AllowedItemType)
{
    throw new Exception("Invalid Category.");
}
```

---

## সুবিধা

✔ Strong Validation

✔ Wrong Data ঢুকবে না

✔ Future Proof

✔ Database নিজেই Business Rule বুঝতে পারবে।

---

## অসুবিধা

Migration লাগবে।

# Solution 4: `IsServiceCategory` Flag

Category Entity:

```csharp
public bool IsServiceCategory { get; set; }
```

---

## Table

|Name|IsServiceCategory|
|---|---|
|Technical Services|true|
|Finished Goods|false|

---

## Validation

```csharp
if(product.ItemType == Service &&
   !category.IsServiceCategory)
{
    throw new Exception();
}
```

---

## সুবিধা

Simple।

---

## অসুবিধা

আগামীতে যদি নতুন ItemType আসে:

```text
Asset
Consumable
SemiFinished
```

তখন:

```text
IsAssetCategory
IsConsumableCategory
IsSemiFinishedCategory
```

অনেক Flag তৈরি করতে হবে।

Design খারাপ হয়ে যাবে।
