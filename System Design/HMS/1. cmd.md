**Concept ঠিক, কিন্তু state persistence এখনই blindly lock না করাই ভালো।**

# ৯. আরেকটি খুব গুরুত্বপূর্ণ বিষয়

Claude বলেছে:

> Journey regenerable / advisory; requirement + order durable transactional record।

এই statement-টা **আমি পুরোপুরি lock করার আগে clarify করতাম।**

কারণ Journey-এর কিছু অংশ regenerate করা যেতে পারে, কিন্তু patient ইতিমধ্যে operationally এগিয়ে গেলে পুরো journey delete/rebuild করা dangerous হতে পারে।

উদাহরণ:

```
Blood Collection → Completed
X-Ray → InProgress
Consultation → Pending
```

এখন journey regenerate করলে historical operational events হারানো যাবে না।

তাই safer principle:

> **Journey plan may be regenerated/replanned only when it does not destroy or rewrite already-executed patient history.**

অর্থাৎ:

```
Planning data
    → potentially rebuild/replan

Executed history
    → NEVER overwrite
```

এটা খুব গুরুত্বপূর্ণ।
