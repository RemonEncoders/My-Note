# আরও dangerous problem

ধরি:

Doctor একটা Purchase Requisition Save করলো।

আপনি করছেন:

```csharp
entity.CreatedBy = _currentUserService.UserId;
```

আপনি ভাবছেন:

```text
CreatedBy = doctor
```

কিন্তু save হচ্ছে:

```text
CreatedBy = dev
```

এটা data corruption।

# Claude-এর Solution কেন কাজ করে?

Claude বলছে:

```csharp
public Guid UserId
{
    get
    {
        Guid.TryParse(
            _contextAccessor.HttpContext?.User?
                .FindFirstValue(ClaimTypes.NameIdentifier),
            out Guid value);

        return value;
    }
}
```

এখানে আর constructor-এ value save করা হচ্ছে না।

---

প্রতিবার:

```csharp
_currentUserService.UserId
```

call করলে:

```text
HttpContext.User
```

থেকে fresh value read করবে।

# Final Recommendation

আমি personally এভাবে লিখতাম:

```csharp
public Guid UserId
{
    get
    {
        Guid.TryParse(
            _contextAccessor.HttpContext?.User?
                .FindFirstValue(ClaimTypes.NameIdentifier),
            out Guid value);

        return value;
    }
}

public bool IsAuthenticated =>
    _contextAccessor.HttpContext?.User?.Identity?.IsAuthenticated ?? false;

public string Name =>
    _contextAccessor.HttpContext?.User?.Identity?.Name ?? "";
```

এবং constructor:

```csharp
public CurrentUserService(
    IHttpContextAccessor contextAccessor,
    UserManager<ApplicationUser> userManager)
{
    _contextAccessor = contextAccessor;
    _userManager = userManager;
}
```
