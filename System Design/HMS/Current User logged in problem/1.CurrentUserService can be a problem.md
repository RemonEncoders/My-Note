# Step 1: CurrentUserService কী করছে?

আপনার constructor:

```csharp
public CurrentUserService(
    IHttpContextAccessor httpContextAccessor,
    UserManager<ApplicationUser> userManager)
{
    _contextAccessor = httpContextAccessor;
    _userManager = userManager;

    Guid.TryParse(
        httpContextAccessor.HttpContext?.User?
            .FindFirstValue(ClaimTypes.NameIdentifier),
        out Guid value);

    UserId = value;
    IsAuthenticated =
        httpContextAccessor.HttpContext?.User?.Identity?.IsAuthenticated ?? false;
    Name =
        httpContextAccessor.HttpContext?.User?.Identity?.Name ?? "";
}
```

এখানে কী হচ্ছে?

যখন `CurrentUserService` object তৈরি হচ্ছে, তখনই:

```text
UserId = বর্তমান User এর Id
Name = বর্তমান User এর Name
IsAuthenticated = বর্তমান Login Status
```

একবার read করে properties-এ save করে ফেলছে।

# Step 3: Problem কখন হয়?

Claude বলছে:

> PurchaseModel.cs root container থেকে resolve করছে।

মানে সম্ভবত:

```csharp
Startup.AutofacContainer.Resolve<ICurrentUserService>()
```

অথবা:

```csharp
var currentUser =
    Startup.AutofacContainer.Resolve<ICurrentUserService>();
```

এটা root container থেকে resolve করা হচ্ছে।

---

## Root Container কী?

Application start হওয়ার সময় একটা global container তৈরি হয়।

```text
Application Start
       ↓
Root Container তৈরি
```

এটা পুরো application life পর্যন্ত বেঁচে থাকে।

---

যখন আপনি:

```csharp
Startup.AutofacContainer.Resolve<ICurrentUserService>()
```

করেন, তখন request scope ignore হয়ে যায়।
