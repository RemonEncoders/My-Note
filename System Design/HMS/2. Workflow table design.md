# আমি আরও একটি Design Suggest করবো (Enterprise Best Practice)

আমি `Version` Column আলাদা করে রাখার চেয়ে **Workflow Definition Immutable** রাখার পক্ষপাতী।

অর্থাৎ **Workflow একবার Publish হলে আর Edit করা যাবে না**।

নতুন পরিবর্তন মানেই **Clone Workflow**।

উদাহরণ:

|WorkflowId|WorkflowName|Status|
|---|---|---|
|3|High Value Approval|Archived|
|4|High Value Approval|Active|

এখানে `WorkflowId`-ই Version-এর কাজ করছে।

- Workflow 3 = পুরোনো Definition
- Workflow 4 = নতুন Definition

তাহলে `PurchaseRequest` শুধু `WorkflowId` রাখলেই যথেষ্ট। আলাদা `Version` Column-এর প্রয়োজন হয় না।

এটাই অনেক Enterprise System-এর পছন্দের Design, কারণ:

- Workflow Definition কখনো পরিবর্তিত হয় না (Immutable)।
- Audit করা সহজ।
- Running PR কখনো নতুন Rule দ্বারা প্রভাবিত হয় না।
- Code অনেক সহজ হয়—`PurchaseRequest.WorkflowId` থেকেই সব Stage বের করা যায়।
