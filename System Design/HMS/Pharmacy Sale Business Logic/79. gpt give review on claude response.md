## তবে একটা জিনিস Claude-কে verify করতে বলতাম

সে বলেছে:

> journal existence guard

আমি এটাকে শুধু

> "Journal আছে কি?"

এই check-এ সীমাবদ্ধ রাখতাম না।

কারণ দুইটা concurrent request এভাবে চলতে পারে:

```
Request A
Check -> Not Exists

Request B
Check -> Not Exists

A Insert

B Insert
```

দুইজনই "Not Exists" দেখে ফেলতে পারে।

অর্থাৎ **check-then-insert একা concurrency-safe নয়**।

যদি "existence guard" বলতে শুধু query বোঝায়, সেটা যথেষ্ট নয়।

এটার সঙ্গে database constraint বা atomic claim থাকতে হবে।
