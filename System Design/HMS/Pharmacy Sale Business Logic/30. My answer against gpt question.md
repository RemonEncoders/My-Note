## কেন `ProductId1` তৈরি হয়?

EF Core Relationship Discover করার সময় তিনটা জিনিস দেখে:

```text
Navigation Property
        +
Foreign Key Property
        +
Fluent Configuration
```

আপনার ক্ষেত্রে:

### Entity

```csharp
public Guid ProductId { get; set; }

public Product Product { get; set; }   // <-- আপনি নতুন যোগ করেছেন
```

### কিন্তু Configuration

এখনও পুরোনো Style-এ আছে:

```csharp
builder.HasOne<Product>()
       .WithMany()
       .HasForeignKey(d => d.ProductId);
```

এখানে EF বুঝতে পারে:

- `ProductId` নামে একটা FK আছে।
    
- `Product` নামে একটা Navigation-ও আছে।
    
- কিন্তু Fluent API Navigation-টাকে Explicitly Bind করছে না।
    

ফলে EF অনেক সময় ধরে নেয় এগুলো **দুটি আলাদা Relationship** হতে পারে এবং নতুন একটা **Shadow Foreign Key** বানায়:

```text
ProductId1
```

## সঠিক Configuration হবে

```csharp
builder.HasOne(d => d.Product)
       .WithMany()
       .HasForeignKey(d => d.ProductId);
```

এতে EF-কে পরিষ্কারভাবে বলা হচ্ছে:

> "`Product` Navigation-টাই `ProductId` Foreign Key ব্যবহার করবে।"

তখন `ProductId1` আর তৈরি হবে না।
