## 1. Part A (Atomic status claim)

✅ **Approve this.**

Instead of

```text
Read Status

    ↓
Update Status
```

which has a race condition,

it becomes

```sql
UPDATE PharmacyCustomerPayment
SET Status = Final
WHERE Id = @Id
  AND Status = Draft
```

If

```
RowsAffected == 1
```

this request "won."

If

```
RowsAffected == 0
```

someone else already finalized it.

This is an excellent DB-level idempotency pattern.
