# ১. Mapping Strategy — আমি একমত ✅

এখানে Claude যা বলেছে, সেটা Architecture-এর সাথে মিলে যাচ্ছে।

```
SaleItem.ProductId
        ↓
Drug.ProductId
        ↓
Drug.Id
        ↓
PharmacyItemStock.DrugId
```

এটা **Hardcoded Reverse Lookup** নয়।

এটা আপনার Published Product Pattern-এরই অংশ।

আর যেহেতু

```
Drug.ProductId
```

Unique,

তাহলে

```
ProductId → DrugId
```

সবসময় Deterministic।

এই সিদ্ধান্তের সাথে আমি একমত।
