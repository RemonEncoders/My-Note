# আমি Claude-কে যা বলতাম

> Analysis ভালো হয়েছে। Dropdown অবশ্যই GeneralConfig (Payment Type) থেকে আসবে, PaymentMethod table থেকে না।
> 
> কিন্তু category → GL mapping-এর জন্য নতুন mechanism design করার আগে existing ACARE accounting configuration পুরোটা analyze করো।
> 
> বিশেষ করে বের করো:
> 
> - Payment Category থেকে GL বর্তমানে কীভাবে resolve হয়।
>     
> - Admin কোথায় Cash/Bank/Card-এর GL configure করে।
>     
> - Existing reusable mapping/service আছে কি না।
>     
> 
> যদি reusable mechanism থাকে, সেটাই ব্যবহার করব। নতুন mapping layer তখনই বানাব, যখন নিশ্চিত হব existing architecture এটা support করে না।
