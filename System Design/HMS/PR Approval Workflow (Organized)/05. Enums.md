# 05 · Enums to Add

**Location:** `HMS.Common/Enums`

---

```csharp
EnumPRApprovalStatus : Draft=1, PendingApproval=2, Approved=3, Rejected=4, Cancelled=5

EnumApprovalAction   : Approved=1, Rejected=2            // future: Returned=3

EnumWorkflowStatus   : Draft=1, Published=2, Archived=3
```

---

## কেন আলাদা enum

| Enum | কেন দরকার |
|---|---|
| `EnumPRApprovalStatus` | Existing `EnumPurchaseRequisitionStatus`-এ কোনো approval state নেই। নতুন enum আলাদা রাখলে existing code ভাঙে না (A5)। |
| `EnumApprovalAction` | `PurchaseApproval` log-এ প্রতিটি action কী ছিল (Approved/Rejected)। ভবিষ্যতে `Returned` যোগ হবে। |
| `EnumWorkflowStatus` | HMS rule অনুযায়ী `IsActive/IsDeleted` শুধু soft-delete; workflow lifecycle আলাদা enum-এ (দেখুন [02](<02. Existing System Context.md>) §4)। |

---

## Enum coexistence

- নতুন `ApprovalStatus` → approval process চালায়।
- Existing `EnumPurchaseRequisitionStatus (Inactive/Draft/Final/Completed)` → document lifecycle-এর জন্য আলাদা থাকে।
- দুটো পাশাপাশি চলে, কোনো breaking change নেই।
