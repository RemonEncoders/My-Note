## এক নজরে design

- PR-এর **amount + currency** দেখে একটা **Approval Policy** match হয় → সেটা একটা **Workflow** নির্দেশ করে।
- Workflow-এর কতগুলো **Stage** থাকে (Stage 1 = Manager, Stage 2 = GM …), প্রতিটি Stage একটা **Role**-এর সাথে বাঁধা।
- PR submit করলে Workflow **snapshot** হয়ে PR-এ বসে; তারপর stage-by-stage sequential approval চলে।
- সব stage approve হলে PR **Approved**; কেউ reject করলে **Rejected** (resubmit করলে stage-1 থেকে নতুন cycle)।
- Workflow একবার **Published** হলে immutable — পরিবর্তন মানেই পুরো workflow **clone**।

সব রকম রুল **data-driven / configurable** — নতুন threshold বা approver যোগ করতে কোনো code পরিবর্তন লাগবে না।
