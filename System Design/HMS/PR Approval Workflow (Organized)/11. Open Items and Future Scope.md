## 🟠 Open / Undecided (code শুরুর আগে সিদ্ধান্ত দরকার)

### 1. `RoundNo` on `PurchaseApproval` — **keep নাকি drop?**

Reject → resubmit করলে নতুন approval cycle হয়।

- **Keep:** `RoundNo` থাকলে "১ম cycle-এ কে reject করেছিল, ২য় cycle-এ কী হলো" — history পরিষ্কার আলাদা করে দেখা যায়।
- **Drop:** rows তবু থেকে যাবে, কিন্তু cycle আলাদা করা যাবে না।

> ⏳ **এটাই একমাত্র জিনিস যা code শুরুর আগে বলতে হবে।** সিদ্ধান্ত: `"code লেখো" + RoundNo (keep / drop)`।

### 2. Enum coexistence — ✅ নিষ্পত্তি হয়েছে

নতুন `ApprovalStatus` approval চালাবে; existing `EnumPurchaseRequisitionStatus (Final/Completed)` document lifecycle-এর জন্য থাকবে। (blocker নয়।)
