# 07 · Approval State Flow (Sequential Engine)

> State machine: `Draft → PendingApproval → Approved / Rejected / Cancelled`

---

## পুরো flow

```text
Create ──► ApprovalStatus = Draft            (amount free-edit)

Submit ──► resolve policy → snapshot PR.WorkflowId
                          → CurrentStageNo = MIN(StageNo of that workflow)
                          → ApprovalStatus = PendingApproval   (amount edit now BLOCKED)

At CurrentStage:
  Approve  (acting user must hold stage.RoleId):
      → insert PurchaseApproval(Action = Approved)
      → next = first StageNo > CurrentStageNo   (ORDER BY StageNo)
      → if next exists:  CurrentStageNo = next
        else:            ApprovalStatus = Approved, CurrentStageNo = null

  Reject:
      → insert PurchaseApproval(Action = Rejected)
      → ApprovalStatus = Rejected, CurrentStageNo = null   (flow stops)

Rejected ──► creator edits + Resubmit ──► NEW cycle from MIN(StageNo)
                                          (আগের PurchaseApproval rows history হিসেবে থেকে যায়)

Cancel (creator) ──► ApprovalStatus = Cancelled
```

---

## ধাপগুলো ব্যাখ্যা

| Step | কী ঘটে |
|---|---|
| **Create** | PR তৈরি; status `Draft`; amount free-edit (A4)। |
| **Submit** | Policy resolve → `WorkflowId` snapshot → `CurrentStageNo = MIN(StageNo)` → status `PendingApproval`; এখন থেকে amount edit blocked। |
| **Approve** | Acting user-এর কাছে `CurrentStage.RoleId` থাকতে হবে → log row insert → পরের stage (`ORDER BY StageNo`)। পরের stage না থাকলে PR **Approved**, `CurrentStageNo = null`। |
| **Reject** | Log row insert → status **Rejected**, flow বন্ধ (A6)। |
| **Resubmit** | Rejected PR creator edit করে আবার submit → **stage-1 থেকে নতুন cycle**; আগের log rows থেকে যায়। |
| **Cancel** | Creator PR তুলে নিলে status **Cancelled**। |

---

## key implementation notes

- **Next stage `CurrentStageNo + 1` করে বের করা হবে না** — বরং `ORDER BY StageNo`-তে প্রথম বড় StageNo। (B3 defensive; immutable workflow-এ এমনিতেই contiguous থাকবে।)
- "কে pending" আলাদা করে store করা হয় না — Workflow stages + `CurrentStageNo` থেকে derive হয় (B5)।
- Approval log (`PurchaseApproval`) row **শুধু action-এর সময়** তৈরি হয়, আগে থেকে সব pending row বানানো হয় না।
